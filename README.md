# Projeto Agendamento de Consultas Médicas

## Descrição do Projeto

Este repositório contém a atividade de Gestão de Riscos aplicada ao projeto de desenvolvimento de um aplicativo móvel para agendamento de consultas médicas.

O aplicativo contempla funcionalidades de:

- Cadastro de pacientes;
- Gestão da agenda médica;
- Agendamento de consultas;
- Notificações automáticas;
- Integração com sistema externo de prontuário eletrônico.

O projeto encontra-se em fase intermediária de desenvolvimento e apresenta desafios relacionados à integração externa, mudanças de requisitos e aumento da carga de trabalho da equipe.

## Objetivo do Exercício

Aplicar práticas de gerenciamento de riscos em projetos por meio das seguintes etapas:

1. Identificação dos riscos;
2. Análise qualitativa dos riscos;
3. Definição de estratégias de resposta;
4. Comunicação para stakeholders.
